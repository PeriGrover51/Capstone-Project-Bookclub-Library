User Stories (completed):
- While logged out:
    - Users can sign up as a member and log in
    - Users can view a library of previous books read in the club, with general info
    - Users can view past sessions or the current session page for info on the current book and meeting / session details
- While logged in:
    - Members can add or edit books in the library
    - Members can add or edit past sessions or the current session
    - Members can view nominations of books to be voted on for the next book to read + the member who nominated them
    - Members can add nominations
    - Members can edit or delete their own nominations
    - Members can vote on all current nominations (on a 1-5 scale). They can edit their votes as many times as they want, but can only cast 1 vote per nomination.

Stretch Goals (completed):
- Voting / Nominations page has 'Add to Library' button that creates a new library book entry from that nomination
- Voting / Nominations page has a 'Clear All' button that deletes all current nominations
- Votes are hidden until a member clicks the 'Reveal Votes' button, which displays the votes for each nomination
- Members can favorite or unfavorite books in the library

Additional Notes:
- The library is allowed to hold duplicates as long as the date (when it was read) is different, since sometimes bookclub will re-read books.
